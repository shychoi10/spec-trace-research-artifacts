# Qualified-claim diagnostic record: CR0002 development witness

Run `python3 -B verify.py .` from this extracted directory (Python 3.10+, standard library only).
No network, model, installation or research repository is required.

Read specification.json for the unit and assessment meanings, then record.json for one worked
source/input/answer/action/cost record. Original source projection, frozen author reference,
inputs and all six saved answers/provider results are included unchanged. A manifest binds them
to their exact original locators. Those locators describe provenance; the verifier does not follow them.

The verifier checks file identities, the two selected source witnesses in supplied inputs,
unchanged Q2 fields/actions and complete provider call charges. It DOES NOT rejudge semantic
coverage or certify every supplemental assertion, expert gold, source rendering, normative
incorporation, causal performance or a particular device. Coverage labels are development
author interpretations. The generic reask and ledger/audit both recover the exhibited omission;
the latter costs more. Physical and dependent logical call counts remain separate.

This is a reusable development diagnostic artifact, not the complete semantic benchmark.
Sources are attributed to 3GPP TS38.391 and CR0002r1/R2-2601230; original rights remain with
their respective owners. Clause/version/rationale links and edit alignment build on DeepSpecs,
CR-Eval and ARIES; this interface is not claimed to invent those links. See the manuscript
references and existing artifact repository for original native-source provenance and citations.
Packaging adds no new model calls. Public upload, anonymous same-host download and independent
external use are distinct states and are reported separately from the immutable local preparation.
