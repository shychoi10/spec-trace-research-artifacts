# Scoped tracing obligation development resource

Three already-exposed dependent components (RAN4 LQ01, RAN3 CR0019, RAN2
CR2273 plus observed TS36.331 13.2/13.3) contain 18 author-constructed
propositions. Questions, selected source packets, author references and
policies were frozen before six first authenticated-Codex predictions.
Direct contextual attribution and explicit claim tracing receive byte-identical
source/question inputs, once per component and condition. No reference is
supplied to predictions, no retry, no independent expert gold or held-out
accuracy claim. Both preserve all 18 scoped obligations in author readback:
8 recoverable supported facts, 5 refuted promotions and 5 inventory-bound
unknowns. Correct unknowns do not recover absent content. Literal checking
finds no defects in 74 answer quotes. The 30 extra trace units were also read.

The three collision witnesses are disclosed lossy representation ablations,
not faithful implementations of prior research. Full contextual AIS, ARIES,
version-aware CR rationale or dialogue-act records can retain these facts.
This resource supplies concrete regression questions and evidence boundaries;
it establishes no novel attribution theory or general tracing advantage.

The native snapshot files retain their original standards/CR notices and
authorship. Selected textual projections, ordinary/deleted layers, proposed
and observed published wording are distinct. This is selected-source replay,
not a certified rendering or full native email quotation-chain benchmark.

Run `python3 verify.py .` with the standard library. It checks package hashes,
reconstructs each full selected source packet and actual paired input, and
replays first answer IDs/literal quotes. It makes no model calls and does not
certify semantic accuracy. Native selected RAN2 projections were additionally
read back locally against original Word text nodes/PDF character spans; that
bounded check is retained separately. Source-level original paths in preserved
protocols/results are provenance, not dependencies needed by this replay.

Costs retain all six first inference calls: direct 32,774 input/3,280 output
tokens and 67.29 summed request seconds; trace 32,904/7,335 and 132.40 seconds.
No extraction/judge model pass. Preparation, author inspection and deployment
are not included as measured monetary cost or productivity. These are one-shot
durations, not causal latency estimates. Publication, anonymous download and
independent external use have distinct states; no DOI or external user is
claimed by this package.
