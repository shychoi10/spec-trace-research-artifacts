# Retained configuration development intervention

The exposed three-CR P5 source pool, original first answers and original
question-specific assessment are preserved in prior/. The new frozen rule
prioritizes unchanged blocks in a different table of an edited clause when
they share literal configuration labels with changed blocks. Caption,
endpoint occurrences, context bundles and deduplication are shared. The
contextual comparator sees all retained blocks, including the same alternative
block, but ranks them with the preserved BM25 scores. Cover context precedes
retained priority; edit/version closure and BM25 backfill follow. Atomic
packing uses the same 12,000 unique source-text-character cap. No reference,
PC2 constant, case ID or numerical answer is used to select evidence.

Nine condition inputs use five unique first observations: three inherited
P5 edit/version first responses and two new CR1484 first calls. Byte-identical
input plus policy is reused, never rerun. Both new inputs and first answers
recover the unchanged PC2 783 MHz/5 MHz/25 RB setting and all seven ordinary
changes. This is a repair on one exposed development case, not evidence of
relation-selector superiority or general accuracy. Added/displaced sources,
remaining reader omissions, boundaries and actual costs are explicit.

Contextual/table retrieval, version linking and contrastive retrieval are
established prior ideas, including DeepSpecs, RAGonite and CF-RAG. This is
neither a faithful reproduction nor a claim to invent those principles.
The source pool remains native-derived selected excerpts; full rendering,
structural revisions, equations and reference resolution are not certified.
There are no independent expert labels, held-out scores, DOI or observed users.

Run python3 verify.py . with the standard library. The verifier hashes every
listed file, replays the preserved P5 instrument, reconstructs both retained
rules and all nine actual inputs, and checks the five unique answer quote
sets. It neither calls a model nor rerenders native Word nor grades meaning.
Original repository paths and unused protocol bindings record provenance;
portable replay reads only this package. Upload and same-host credential-free
download/replay are separately logged outside the prepared package.
