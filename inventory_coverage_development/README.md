# Inventory coverage development resource

This separate P11 development resource contains three metadata-selected cases.
Selection and eligibility metadata are preserved in selection.json. The saved
mixed_catalogue and intact allocations use whole source roles and complete
declared clauses as controls, rather than selecting excerpts from model outputs.
The frozen policy names are answer_aware, inventory_optimized and inventory_first.

Inventory-first reuses the full identical intact initial input and its recorded
physical result. Logical workflows charge their actual declared result bindings,
including initial diagnosis where applicable; physical calls are deduplicated by
result binding. Reuse does not remove logical charges. Actual counts and measured
costs are in completed_first_call_accounting.json and are not preset by this
publisher. Optional unobserved token usage remains null, with missing fields and
partial observed sums recorded explicitly; observed durations are not causal
latency or total cost of ownership. Source preparation and author readback are
outside model-call costs.

This is development material and author interpretation, not independent semantic
gold. Root textual-comparison readback completion does not assert that every
requested fact was observed. The package preserves saved source projections,
inputs, first returns, operations, admissions, completion guards and hash-bound
protocol dependencies. Its replay does not rerender native documents, run a
model, assess answer meaning, or reverify the host CLI executable. CLI binding
metadata remains recorded; the executable and authentication files are excluded.

Run python3 -B verify.py /path/to/unpacked/package, and separately run
python3 -O -B verify.py /path/to/unpacked/package. Both use only the standard
library and saved package bytes. manifest.json covers every member other than
itself; source_locators.json maps original artifact bindings to package members.

Canonical research records, manuscripts, reviews, external memory, protected
email source bodies and CLI authentication are excluded. Existing public RAN
case native files are preserved as recorded bytes, without native rerender.
Local preparation, repository upload and credential-free download replay are
separate recorded states. No DOI or independent external users are claimed.
An anonymous check on the preparing host is not independent external use.
