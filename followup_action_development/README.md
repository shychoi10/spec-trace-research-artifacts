# Source-aware follow-up action development resource

Three new-specification RAN2 cases were selected by frozen metadata order before
technical source reading. The initial questions, author source references,
source inventory and protocol precede every model answer. All cases are kept,
including an editorial-only change. Native CRs, observed base/target files and
saved text projections retain their distinct roles. No protected email bodies.
Native/package/literal-reference overlap checks do not certify independence:
some specification references lead to previously exposed sources.

Each case has a deliberately withheld-target and an intact source allocation.
These are controlled source ablations, not natural retrieval-failure samples.
All three policies share each initial answer and diagnosis. Source-aware uses
the first recommended actions without an author override; always-ask rechecks
the supplied text; always-acquire obtains any remaining target excerpts.
All use the same three explicit questions and answer allowance. Already
successful initial answers and unsupported authority/device unknowns remain.
The author readback is not expert gold or general model accuracy. Acquisition
uses a prepared question-scoped catalogue, not an end-to-end search evaluation.

Run python3 -B verify.py . and python3 -O -B verify.py . with the standard library.
Replay checks every distributed file, frozen protocol dependencies, source-scope
selection, initial allocations, first-recommendation routing, actual follow-up
inputs, literal quotes, raw event/answer/usage and closed CLI dispatch provenance.
It independently recomputes logical policy costs and physical unique-call costs.
Initial diagnosis costs are charged to every logical workflow; STOP adds no
second call. Identical follow-up inputs physically share a returned answer.
Recorded sharing metadata errors and one transient on-disk versus process-loaded
admission-wrapper binding discrepancy are retained with separate errata. No
scientific input or returned answer is replaced, and there is no reroll.

Replay does not execute inference, rerender native Word files, certify semantics,
independence, past empty directories or absence of unobserved executions. Native
files and saved projections are distributed; prior-art PDFs, historical source
libraries, host CLI/authentication and external-memory files are not. Binding
checks cover distributed protocol/input/operation/native files, not every external
historical audit dependency. Local preparation, upload and credential-free
same-host download are separate states. No DOI or observed external users.
