# Evidence acquisition development resource

Three RAN4 submitted CRs (TS38.101-1 CR3217, -2 CR0842, -3 CR1484) and
observed affected-clause endpoint excerpts support 12 author-derived requests.
Metadata selection and question templates precede new technical readback;
author references precede all nine first authenticated-Codex calls and are
withheld from acquisition and answers. The requests in the CRs are authentic;
these four QA templates are authored, not naturally observed engineer queries.
The cases are related RF series with shared package/literal-reference
dependencies, not three certified independent test components or expert gold.

Every mode uses the same contextual direct instruction and exact-text dedup
with all source/role/version occurrences and explicit native run-format tokens.
The two retrieval modes have a 12,000 actual source-text-character cap per CR
across four questions. Metadata/serialization are extra and observed token
costs are unequal. Shared BM25 controls include case/spec filtering,
question/role stratification, neighbors, headers and full explicit configuration
blocks. The candidate prioritizes technical cover, tracked edits, same-clause
observed versions and retained prose before the same BM25 backfill. These
established operations are not a new neural architecture or a reproduction
of DeepSpecs, IRCoT, Adaptive-RAG or AutoSearch. Full-selected direct supplies
the entire deduplicated bounded pool, not all native standards; row1 has
identical inputs in all modes after deduplication.

Read author_answer_readback.json and completed_first_call_accounting.json
for the actual first results, omissions, boundaries and costs. Positive
technical recovery is separate from approval/causation and measurement/
deployment boundaries; correct inventory unknowns are not positive recovery.
All first calls and literal defects remain; no retries or model judge calls.
The Word view resolves inline tokens only; structural revisions, inherited
styles, equations, fields and full rendering remain unresolved. Native
snapshots retain original notices/authorship and do not certify approval.

Run `python3 verify.py .` with the standard library. It checks file hashes,
recomputes the deterministic deduplication, metadata/BM25/context source
selection and exact actual inputs, then replays every first answer quote.
It does not call a model, certify meaning or rerender/reproject native Word.
Original repo paths in protocols are provenance, not replay dependencies.
Publication/upload, credential-free same-host replay and independent reuse
are separate states. There are no expert human labels, DOI or observed
external users. No general accuracy, superiority, causal latency or TCO.
