# Matched inventory-first saved-return development resource

This packet contains three exposed change-request cases: CR3217, CR0842 and
CR0002. All four policies complete the same selected saved inventory before
answering. Target-withheld and intact allocations converge on the same acquired
input and share physical first returns. The 24 paired workflows are dependent;
there are 12 unique case/policy workflows and 20 saved physical first calls.

The comparisons are stop, one generic reanswer, answer-first diagnosis with an
actual conditional Ask, and source-only ledger/audit with an actual conditional
Ask. Ledgers precede first answers. Every actual Ask receives one reanswer with
only question IDs/source IDs; no diagnostic facts, quotes, ledger facts or author
requirements are injected. Extra-detail asks and unsuccessful recovery remain.

Run the standard-library verifier without models or network:

    python3 -B verify.py .
    python3 -B -O verify.py .

Both commands recompute byte identities, actual occurrence/body supply, paired
inventory completion, exact followup input recipes, JSON/literal evidence,
source-only ledger ordering, one-followup dispatch, raw CLI usage and all physical
and dependent logical charges. Cache is included in input; reasoning is included
in output. Request-duration sums exclude acquisition I/O, preparation, author
readback and manuscript review and are not pipeline elapsed time or total cost.

The immutable author criteria and root readback are exposed annotations, not
independent expert gold. Essential condition recovery, assigned-question placement
and whole-response support are separate. This verifier certifies saved mechanical
replay only; it does not regenerate model outputs, certify every supplemental
claim, rerender native source documents or rerun production retrieval. Native
and runtime provenance locators in raw records are opaque and must not be opened.
The original run-control and followup-admission records are hash-bound outside
the packet; method.json is their explicitly selected scientific projection.
